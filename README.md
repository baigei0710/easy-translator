# AITools - 极简 AI 与快捷翻译工具集

这是一个包含多个极简翻译小工具的集合，提供了基于本地大模型（Ollama）以及在线 API 的翻译方案，支持桌面悬浮窗和网页端使用。

## 包含的工具

### 1. 本地 AI 翻译工具 (`app.py`)
一个基于本地 Ollama 服务的极简桌面悬浮翻译应用，完全依赖本地运行的大语言模型，保护隐私。

**特点:**
- 原生 Python (Tkinter) 桌面悬浮应用，开箱即用。
- 自动检测系统剪贴板变化并自动翻译。
- 自动拉取本地 Ollama 服务中可用的模型列表，可自由切换模型。
- 界面极简，窗口支持置顶。

**使用方法:**
无需额外依赖，确保本地已启动 Ollama 服务（默认端口 `http://localhost:11434`），在终端中运行：
```bash
python3 app.py
```

### 2. 划词翻译悬浮插件 (`popover_translator.py`)
一个轻量级的全局快捷键划词翻译工具，使用在线免费翻译接口（首选有道，备用 MyMemory）。

**特点:**
- **划词速译**: 无需手动复制，选中文本后按下快捷键自动抓取并翻译。
- **保护剪贴板**: 抓取文本后自动恢复用户原有的剪贴板内容，不污染剪贴板历史。
- **免 Key API**: 使用免费的高速在线 API，无需配置即可使用。
- **智能双向检测**: 自动识别中英文，进行中译英或英译中。
- **极简半透明卡片**: 翻译结果以 90% 半透明悬浮窗展示，跟随鼠标位置，按 `Esc` 一键关闭。

**环境依赖:**
需要安装 `pynput` 库以支持全局快捷键和模拟按键：
```bash
pip install pynput
```

**使用方法:**
```bash
python3 popover_translator.py
```
运行后程序在后台静默运行。选中文本后，按下快捷键 `Alt+Shift+T` 或 `Cmd+Shift+X` (Mac) 即可弹出翻译悬浮窗。

### 3. 网页版翻译工具 (`translator_app.html`)
一个纯前端实现的本地 Ollama 翻译 UI，可以在浏览器中直接打开。

**特点:**
- 极轻量，单 HTML 文件，无需后端服务器。
- 直接请求本地 Ollama 接口，支持流式输出翻译结果。
- 包含一键粘贴、一键复制等便捷按钮。

**使用方法:**
直接双击打开 `translator_app.html` 即可在浏览器中使用。
*(注意：同样需要本地已启动 Ollama 服务。如有跨域问题，请确保 Ollama 允许 CORS 请求)*

---
**关于 Ollama 的安装与使用:**
请访问 [Ollama 官方网站](https://ollama.com/) 下载并安装。安装后可以通过 `ollama run <model_name>` (例如 `ollama run qwen`) 下载并运行大模型。
